To set or change the admin website password (not VPS SSH), open:

MongoDB, Firebase, and domain URLs live in the same file — do not delete existing lines you are not changing.

Step 6

Add or update admin lines in .env.local

In nano, scroll with arrow keys. If these lines already exist, change only the values after =. If they are missing, paste at the bottom. ADMIN_USERNAME=superadmin
ADMIN_USERNAME_ALIAS=RoyalAdmin
ADMIN_PASSWORD=RoyalAdmin2026!
STAFF_DEFAULT_PASSWORD=Staff@2026!
Admin login after restart:
URL: https://zoraaroyal.com/admin
Username: superadmin or RoyalAdmin
Password: value of ADMIN_PASSWORD above (current: RoyalAdmin2026! until client changes it)
Optional staff accounts (same STAFF_DEFAULT_PASSWORD if set): financemanager, coinofficer, operationadmin, chatsupport

Also keep MONGODB_URI, JWT_SECRET, NEXT_PUBLIC_APP_URL, and Firebase paths in this file — see .env.example in the project.
